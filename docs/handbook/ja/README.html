AI 支援ソフトウェア考古学ハンドブック

繁體中文 · English · 日本語

本書は、コードは読めるもののリバースエンジニアリングの経験は必須ではない技術者と、その作業を支援する AI エージェントに向けた手引きです。最初から IDA やエミュレータの操作を知っている必要はありません。まず「この結論は何に支えられているか」を問い、その証拠を得る道具を選びます。

小さな機能について、反証可能な仮説、証拠に基づく仕様、再現可能な比較条件、範囲を誇張しない適合性の声明を書けることを目指します。実行ファイル全体を一行ずつ翻訳する本ではありません。有限のテストを、あらゆる動作についての数学的証明と同一視しません。

目次

章 主題 身につけること
00 原則 内部整合性、参照との一致、利用可能性を分ける
01 証拠 追跡可能な観測を残し、道具が何を見られるか確認する
02 仮説 競合する説明を区別できる検査を設計する
03 仕様のゲート 実装を開始できる条件を判断する
04 判定基準 裁定できる範囲を明示した参照を選ぶ
05 差分テスト 最初の不一致と欠測、許容差を正しく扱う
06 適合性 監査可能で範囲の明確な完了声明を書く
07 エージェントの作業手順 タスクを区切り、ゲートを守り、引き継ぐ
08 失敗パターン 八つの事例から誤りの形成過程を見分ける
付録 一連の検証を通して学ぶ 誤った候補と欠測を含む完全な流れを手計算する

初回は順に読みます。不一致を調査中なら 04〜06 章から入り、01〜03 章で前提を見直してください。付録には自己確認の問いと答えがあり、歴史的なソフトウェアを動かさずに練習できます。

証拠と翻訳の方針

日本語版は先に作成した繁体字中国語の原稿に対応します。章番号、出典 ID、確信度、例の数値は共通です。M1、S3、O2 などは固定出典一覧を参照します。一覧の説明は繁体字中国語ですが、コミットを固定したリンク、パス、ハッシュは言語に依存しません。

出典文書と選定したコードは静的に確認しました。過去の実行結果は元プロジェクトの記録であり、本書のために原版を再実行した結果ではありません。各章でその境界を明示します。一般的な作業上の推奨は主に STRONG_INFERENCE です。リポジトリの必須規則は方針であって、経験則の証明ではありません。合成例の期待値は教材の契約による定義であり、歴史的ソフトウェアの発見ではありません。

用語

用語 意味
証拠／生の観測 解釈と分離され、場所と方法を追跡できる記録
主張／仮説 範囲を持つ断言／判別する検査が必要な説明
来歴 出典、版、場所、取得方法を結ぶ情報
判定基準（オラクル） 特定の比較を裁定する資格のある参照
候補実装 評価される実装
差分検証 宣言した条件で参照と候補を比較すること
適合性 版を持つ契約の、宣言した受入範囲を満たすこと
観測境界 状態を取得するイベントまたは時点
CONFIRMED 明示した範囲で直接の裏付けがある
STRONG_INFERENCE 強い裏付けはあるが直接の接続が不足している
HYPOTHESIS 検査を待つ、もっともらしい説明
UNKNOWN 証拠が不足している、または未解決

DRAFT、READY、CONFORMED は仕様の状態であり、確信度ではありません。作業表は読解と計画のためのもので、公開済みスキーマや API ではありません。本書によって計画中の osa CLI が実装されたわけではありません。
