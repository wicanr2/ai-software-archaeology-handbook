# AI 輔助軟體考古手冊

繁體中文 · [English](en/README.md) · [日本語](ja/README.md)

這本手冊寫給能讀程式、但不一定做過逆向工程的工程師，以及協助他們工作的 AI 代理。
你不需要先會操作 IDA 或模擬器；先學會問「這個結論憑什麼成立」，再選擇取得證據的工具。

讀完後，你應能為一個小功能寫出可反駁的假說、帶證據的規格、可重播的比較條件，
以及不誇大範圍的符合性聲明。這本書不教逐行反編譯，也不把有限測試當成所有行為的數學證明。

## 如何閱讀證據等級

歷史案例沿用[固定來源索引](../inventory.md#固定來源索引)的 M1、S3、O2 等 ID。
這些來源的存在及本文所指出的內容經靜態核對；歷史執行結果是原專案的紀錄，
不是本手冊新做的原版實驗。各章的「來源與主張範圍」說明這個界線。

工程規則是從這些案例萃取的建議，多數屬 `STRONG_INFERENCE`；
本專案強制遵守的工作規範則是規範，不偽裝成經驗定律。
合成案例的預期值由其教學契約定義，不當成任何歷史軟體的發現。
