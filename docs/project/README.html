AI 輔助軟體考古手冊

王俊又 wicanr2｜正式宣傳網站

如何讓 AI 產生的重寫程式，有可回查的證據支持，而不只是一份看起來合理的實作。 本手冊從七個軟體考古專案萃取方法，說明如何保存證據、反駁假說、審查規格， 以及用原版或明確指定的行為基準驗證候選實作。

閱讀：繁體中文 · English · 日本語

PDF 與推廣圖：v.1.0.0-20260905 提供三語完整 PDF、可點選目錄及三組美化流程圖；儲存庫與附件已公開，可直接閱讀與下載。 重建及附件說明見 PDF 發行入口。

核心流程是：證據 → 假說 → 規格 → 行為基準 → 實作 → 差分驗證 → 符合性。 三個語言版本共用章節編號、案例出處與信心等級；繁體中文是先完成的原稿。

本儲存庫的範圍

手冊可直接閱讀 Markdown，不需要安裝程式。九章正文與一份完整教學案例， 涵蓋工程判準、操作步驟、反例與可填寫的工作表。 教學案例是人工設計的合成例子，沒有夾帶原版二進位檔或素材。

手冊完成不表示工具計畫已全部完成。PLAN.md 中的機器可讀模型、 osa 命令列工具與真實介接器仍是後續工作；本儲存庫目前沒有可執行的 osa。

案例根據固定版本的來源文件與指定程式碼整理。歷史結果有明確出處， 但不宣稱本手冊重新執行並驗證了所有原版程式。
